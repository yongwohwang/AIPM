한 장 요약

무엇을 — 국외근무직원의 부임·복귀 안내와 보수·복지 및 HR 규정 문의에 답하는 AI 에이전트. 사내 AI 플랫폼 위에 구축한다.

왜 지금 — ① 매년 2월 정기인사 시기에 부임·복귀 문의가 폭주하는데, 하필 그때 담당자도 교체된다 ② 규정 해석 노하우가 담당자 개인에게만 있어 인사발령마다 리셋된다 ③ 사내 규정 자동 수집 체계가 갖춰져 최신 규정 유지가 처음으로 가능해졌다.

대상 — 1차는 본부 담당자 4~6명(내부 도구), 2차는 국외근무직원 129명(인니 16 · 캄보디아 8 · 국외점포 105).

핵심 설계 — AI는 규정 원문 인용(L1)과 실무 안내(L2)만 답하고, 유권해석(L3)은 답하지 않고 소관부서로 연결한다. 이로써 소관(HR)과 답변 주체(글로벌)가 다른 문제를 구조적으로 해소한다.

성공 판단 — 담당자 수신 문의 건수 감소, 셀프서비스 해결률, 골든셋 정답률. Phase 0에서 baseline을 측정한 뒤 목표치를 확정한다.

지금 필요한 결정 — ① 자료 수집(부임 안내서·국가별 HR 사례) 마감을 다음 정기인사 이전으로 확정 ② HR/직원만족부 사전 협의 ③ 지식베이스 안내서 갱신 담당을 역할 기준으로 지정

1. Executive Summary

국외근무직원의 부임·복귀 절차 문의와 보수·복지·HR 규정 문의는 현재 본부 담당자가 개별적으로 응대한다. 같은 질문이 반복되고, 국가별 안내 자료의 형식이 제각각이며, 규정 해석은 담당자 개인의 경험에 의존한다.

이 프로젝트는 사내 AI 플랫폼 위에 국외근무직원 HR 에이전트를 구축해, 규정을 조항 원문과 소관부서까지 정확히 찾아주고 국가별 부임·복귀 절차를 안내한다. 1차 버전은 담당자 전용 내부 도구로 출시해 답변 품질을 실사용으로 교정한 뒤, 검증된 답변만 국외근무직원에게 단계적으로 공개한다.

목표는 담당자의 반복 응대 부담을 줄이는 것을 넘어, 처리 근거를 시스템에 남겨 담당자가 교체되어도 업무 연속성이 유지되게 하는 것이다.

2. Background & Context

2.1 현재 상태 (AS-IS)

  • 국외근무직원이 부임 준비·보수·복지 관련 사항을 담당자에게 직접 문의한다 (메신저·메일·유선).
  • 담당자가 규정집과 안내 자료를 찾아 개별 회신한다.
  • 답변은 기록되지 않으므로 같은 질문이 반복 발생한다.
  • 국가별 부임 안내 자료의 형식이 통일되어 있지 않다.
  • 규정 해석 노하우와 과거 사례가 담당자 개인의 암묵지로만 존재한다.

2.3 왜 지금인가

① 2월에 모든 것이 겹친다

정기인사발령이 있는 2월에 부임·복귀가 집중된다. 부임자들이 동시에, 대부분 같은 질문을 한다. 그런데 2월은 담당자 본인도 교체되는 달이다.

매년 2월마다, 가장 경험이 적은 담당자가 가장 많은 문의를 받는다.

② 암묵지가 인사발령마다 리셋된다

담당자 작성 자료에 *"담당자 경험 및 노하우(암묵지) 의존"* 이 문제점으로 명시되어 있고, 자료 하단에는 *"인사발령에 따라 업무별 담당자 변동 가능"* 이라고 적혀 있다. 순환보직 구조에서 1~2년마다 지식이 사라진다.

③ 규정 최신성 유지가 처음으로 가능해졌다

사내 규정 자동 수집 시스템이 이미 존재한다. 과거에는 규정을 수동 관리해야 해서 최신성 유지가 불가능했다. 이것이 지금 시작할 수 있게 된 결정적 변화다.

3. Objectives & Success Metrics

3.1 Objective

**국외근무직원이 부임·복귀 절차와 보수·복지 규정을 담당자에게 묻지 않고 스스로 확인할 수 있게 하고,

담당자의 답변 근거(규정 조항·소관부서·과거 사례)를 100% 시스템에 기록해

담당자 교체와 무관하게 일관된 답변이 유지되게 한다.**

3.2 Goals

  1. 담당자가 규정을 찾을 때 조항 원문과 소관부서까지 한 번에 확인할 수 있게 한다.
  2. 국외근무직원이 국가·법인격에 맞는 부임·복귀 절차와 제출 서류를 스스로 확인할 수 있게 한다.
  3. 담당자가 확정한 답변을 사례로 축적해 담당자 교체 후에도 조회 가능하게 한다.
  4. 규정 유권해석이 필요한 질문은 AI가 답하지 않고 소관부서로 연결한다.
  5. 2월 피크 시 담당자에게 도달하는 반복 문의를 줄인다.

3.3 Non-Goals

  1. 개인정보 처리 — 급여액·가족 정보·주소·여권 등을 처리하지 않는다. "규정상 이러한 기준으로 계산됩니다"까지만 안내하고 개인별 실제 금액은 조회하지 않는다.
  2. 급여시스템 연동 — 범위 밖.
  3. 규정 유권해석 — HR/직원만족부 소관이며 AI는 수행하지 않는다.
  4. 사택 임차계약서 검토 및 품의문 작성 — 향후 별도 검토. 본 범위에 포함하지 않는다.
  5. 국외출장 관리 — 향후 검토. 여비규정 Q&A는 Phase 2 이후 저비용으로 추가 가능.
  6. 국외근무직원 직접 공개(1차) — Phase 1은 담당자 전용. 검증된 답변만 Phase 2에서 공개한다.
  7. 담당자 승인 없는 답변 공개 — 어떤 답변도 담당자 확정 없이 대외 공개되지 않는다.

왜 담당자가 먼저인가

국외근무직원 대상 챗봇을 먼저 만들 경우의 리스크는 기술이 아니라 채택이다. 급하면 챗봇 대신 담당자에게 메신저를 보낸다. 더 빠르고, 확실하고, 책임 소재가 명확하기 때문이다. 부임은 2~3년에 1회 발생하는 이벤트라 재방문이 없어 학습 곡선도 타지 못한다.

담당자를 먼저 대상으로 하면 채택이 보장되고(어차피 규정을 찾아야 한다), 답변 품질을 실사용으로 교정할 수 있으며(담당자가 오답을 즉시 잡아낸다), 공개 시점에 이미 검증된 상태가 된다. 담당자가 대체 대상이 아니라 소유자가 되므로 조직 내 저항도 없다.

5. Solution

5.1 핵심 설계 — 답변 책임 등급 (L1 / L2 / L3)

국외근무 지침의 소관은 HR/직원만족부이나 실무 답변은 글로벌사업그룹이 수행한다. 이 분업 자체는 정상이지만, AI 시스템에 넣으면 기록이 남고, 129명에게 동시에 전달되며, "부서 공식 견해"로 인식된다. 지금까지 "담당자의 실무 안내"였던 것이 "부서의 유권해석"처럼 보이게 된다.

모든 답변을 세 등급으로 구분하고 AI는 L1·L2만 수행한다.

등급유형예시소관AI
L1규정 원문 인용"보수·복지 규정 제○조: 주택수당 한도는 ○○"HR 소관이나 인용은 해석이 아님✅
L2절차·실무 안내"부임 전 제출 서류는 ○○이며 양식은 여기 있습니다"글로벌 자체 소관✅
L3해석·판단"배우자가 현지 취업했는데 가족수당 대상인가요?" / "예외 승인 가능한가요?"HR 유권해석 필요❌ 차단

현재 담당자가 하는 답변의 대부분은 이미 L1 + L2다. 진짜 유권해석이 필요한 L3는 현재도 HR에 확인하고 있다.

따라서 AI는 책임 경계를 바꾸지 않는다. 암묵적으로 지켜지던 경계를 명시적으로 만들 뿐이다.

오히려 현재보다 안전하다 — 지금은 담당자가 무심코 L3를 답할 수 있지만, 시스템은 이를 감지해 차단한다.

부수 효과: L3 질문의 대부분이 "제 경우에는?" 형태다. 개인정보를 처리하지 않기로 한 결정(Non-Goal 1)이 자연스럽게 L3를 차단하는 방어 장치로 작동한다.

1담당자로서, 규정을 질문하면 조항 원문과 소관부서가 함께 나와야, 근거를 갖춘 답변을 바로 회신할 수 있다.① 자연어 질문에 관련 조항 원문과 조항 번호가 반환된다 ② 소관부서가 함께 표시된다 ③ 시행일 기준 현행 규정만 검색되며 구 규정은 구분 표시된다 ④ 근거를 찾지 못하면 추측하지 않고 "찾지 못했습니다"로 응답한다 ⑤ 국가·법인격 조건이 없으면 되묻는다(임의 가정 금지) ⑥ 요약보다 원문을 먼저 노출한다
2담당자로서, 유권해석이 필요한 질문에는 AI가 답하지 않아야, 잘못된 공식 견해가 남지 않는다.① "~에 해당하나요", "~예외 되나요", "~위반인가요" 류를 L3로 감지한다 ② L3에는 답변하지 않고 소관부서 확인이 필요함을 안내한다 ③ 소관에 따라 연결 대상이 분기된다(자체 소관 → 담당자 / HR 소관 → HR) ④ 모든 답변에 면책 문구가 고정 표기된다 ⑤ L3 차단 이력이 로그로 남는다
3국외근무직원으로서, 내 부임 국가와 조건에 맞는 준비 항목을 볼 수 있어야, 무엇을 놓쳤는지 담당자에게 묻지 않아도 된다.① 국가 + 법인격 + 가족 동반 여부를 입력하면 개인화된 체크리스트가 생성된다 ② 각 항목에 필요 서류 양식이 직접 링크된다 ③ 기한이 있는 항목은 기한과 남은 일수가 표시된다 ④ 항목별 규정 근거를 펼쳐볼 수 있다 ⑤ 완료/미완료를 본인이 체크할 수 있고 진행률이 보인다 ⑥ 해결되지 않으면 담당자 연결 경로가 항상 노출된다
4담당자로서, 내가 확정한 답변만 국외근무직원에게 공개되어야, 검증되지 않은 답변이 나가지 않는다.① 담당자가 확정한 Q&A만 공개 대상이 된다 ② 한 번의 액션으로 공개 상태로 전환할 수 있다 ③ 공개 답변에는 출처 조항·소관부서·최종 확정일이 표시된다 ④ 미확정 답변은 공개 대상에서 제외된다
5후임 담당자로서, 과거 처리 건을 검색할 수 있어야, 전임자에게 매번 묻지 않고 일관된 기준으로 처리할 수 있다.① 국가·유형·기간으로 과거 건을 검색할 수 있다 ② 각 건은 질문 → 적용 조항 → 답변 → 확정일이 연결되어 표시된다 ③ 예외 처리 건은 사유가 함께 기록된다 ④ 담당자 교체 시 별도 마이그레이션 없이 조회 가능하다

P1 — Should Have

#User StoryAcceptance Criteria
6담당자로서, 내가 수정한 답변이 지식베이스에 반영되어야, 같은 오답이 반복되지 않는다.① 담당자가 수정·확정하면 확정본이 사례로 축적된다 ② 이후 유사 질문에 확정본이 우선 참조된다 ③ 수정 이력과 수정률이 자동 집계된다
7담당자로서, 근거 규정이 개정되면 관련 답변이 표시되어야, 구 규정 기반 답변이 남지 않는다.① 개정 감지 시 해당 조항 근거 확정 답변이 검토필요로 표시된다 ② HR 소관 규정은 정기 재확인 주기가 별도 적용된다
8국외근무직원으로서, 제출 서류 양식을 직접 받을 수 있어야, 양식을 요청하는 문의를 하지 않아도 된다.① 국가·용도를 지정하면 해당 양식이 즉시 제공된다 ② 양식이 개정되면 최신본이 제공된다 ③ 작성 시 유의사항이 함께 표시된다

6. Release Plan

날짜 대신 단계로 표기한다. 각 단계는 이전 단계의 성공 기준을 충족해야 다음으로 넘어간다.

Phase 0 — 검증 (개발 착수 전, 2~4주)

계약서 기능을 범위에서 제외하면서 정량 근거가 문의량 측정에 전적으로 의존하게 되었다. 이 단계는 생략할 수 없다.

  • ☐ ⭐ 담당자 수신 문의 baseline 2주 측정 — 건수, 유형, 건당 소요시간
  • ☐ 문의 100건을 L1 / L2 / L3로 분류 → L1+L2 비율 산출 (A1)
  • ☐ 2월 문의 집중도 확인 — 전년 2월 vs 평월 비교
  • ☐ 규정 골든셋 100문항 작성 (질문 + 정답 + 근거 조항) → 품질 측정 기준선
  • ☐ L3 문항 20개 별도 작성 → 차단 정확도 측정용
  • ☐ 규정 자동 수집 세부 확인 — 개정 반영 주기 / 메타데이터 / 폐지 규정 제외
  • ☐ 규정별 소관부서 목록 작성 (HR 소관 vs 자체 소관)
  • ☐ ⭐ HR/직원만족부 사전 공유 — L1 인용 범위 확인, 답변 검수 협조 요청
  • ☐ 부임 안내서 1개국분을 2주 내 실제 확보 (일정 현실성 검증)

진행 기준: L1+L2 답변 가능 비율 60% 이상 + 자료 수집 일정이 현실적일 것.

Phase 1 — 담당자 전용 규정 Q&A

대상: 본부 담당자 4~6명 / 범위: 보수·복지·인사 규정 (국가 공통 규정 우선)

기능내용
규정 Q&A조항 원문 + 소관부서 표기, L1·L2만 응답
L3 차단유권해석 질문 감지 → 소관부서 연결
사례 축적담당자 확정본 자동 기록
교정 루프확정본이 지식베이스로 재투입

🎯 성공 기준: 골든셋 정답률 90% 이상 + 담당자 주 3일 이상 자발적 사용 + 수정률 20% 이하

보수·복지 규정을 먼저 하는 이유: 규정은 자동 수집되므로 자료 준비가 필요 없다. 부임 안내서는 국가별 정비가 선행되어야 하므로 Phase 2로 둔다.

Phase 2 — 부임·복귀 안내 + 국외근무직원 공개

  • 국가별 부임·복귀 개인화 체크리스트 (Phase 1 기간에 안내서 정비 병행)
  • 제출 서류 양식 직접 제공
  • 담당자가 확정한 답변만 국외근무직원에게 공개
  • 파일럿 1개국(인도네시아 우선) → 순차 확대

🎯 성공 기준: 담당자 수신 문의 40% 감소 + 셀프서비스 해결률 60% + 재문의율 20% 이하

향후 검토 (범위 밖)
