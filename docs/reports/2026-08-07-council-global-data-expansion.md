- **안건:** 전행 데이터 현대화·데이터 분석 프로그램의 글로벌 데이터 확장 요청

## 1. 배경

데이터시스템부(P)는 재무분석/데이터분석 Agent 구축 과정에서, 향후 분석 대상 범위를
전행 데이터 전체로 확장하겠다는 계획을 밝힌 바 있음.

## 2. 애로사항

현재 추진 중인 데이터 현대화 및 데이터 분석 프로그램은 국내 데이터 중심으로 설계되어
있어, 글로벌(해외법인·해외사업장) 데이터는 확장 계획에 명시적으로 포함되어 있지 않음.
이로 인해 글로벌 사업 관련 재무분석·의사결정 시 별도의 수작업 데이터 취합이 필요하며,
전행 통합 분석의 실효성이 제한됨.

## 3. 요청사항

데이터시스템부(P)가 추진 중인 전행 데이터 확장 계획에 **글로벌 데이터(해외법인 포함)**
를 포함하여 줄 것을 요청함.

## 4. 기대효과

- 국내외 통합 데이터 기반의 재무분석·의사결정 체계 구축
- 글로벌 사업 그룹의 데이터 분석 Agent 활용도 제고
- 전행 차원 데이터 거버넌스의 완결성 확보

## 5. 협조 요청 부서

데이터시스템부(P)
