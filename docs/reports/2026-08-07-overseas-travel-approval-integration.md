# [참고자료] 국외출장 결재 프로세스 통합 제안

- **작성일:** 2026-08-07
- **관련부서:** 경영지원그룹
- **안건:** 국외출장 품의 전자결재 - HR시스템 결재 통합

## 1. 현황

- **국내출장:** HR시스템 결재로 일원화되어 있음.
- **국외출장:** 담당자(또는 출장자)가 ① 품의문을 작성하여 전자결재를 받고, ② HR시스템에도
  별도로 출장 결재를 상신해야 함. 즉, 동일 건에 대해 결재를 이중으로 진행하고 있음.

## 2. 문제점

- 동일한 출장 건에 대해 두 개의 시스템에서 각각 결재를 받아야 하므로 업무 중복 발생
- 결재 승인권자 입장에서도 동일 내용을 두 번 확인해야 하는 비효율 발생
- 국내출장 프로세스와의 불일치로 인한 사용자 혼선

## 3. 제안

국외출장 결재를 국내출장과 동일하게 **HR시스템 결재로 일원화**하고, 별도의 품의문
작성·전자결재 절차는 폐지(또는 HR시스템 결재로 대체)하는 방안 검토를 요청함.

## 4. 기대효과

- 출장자 및 결재라인의 이중 업무 제거
- 국내외 출장 프로세스 일원화를 통한 사용자 경험 개선
- 업무 프로세스 혁신 사례 확보

## 5. 협의 요청 부서
